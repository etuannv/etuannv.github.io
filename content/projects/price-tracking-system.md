## Overview

A system that monitors competitor prices across e-commerce platforms daily, stores the data, and surfaces trends through a live dashboard.

## Features

- Daily automated scraping of target product pages
- Price history database with trend visualization
- Alert system for significant price changes
- Clean web dashboard for comparison
