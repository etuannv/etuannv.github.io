## Overview

A system for warehouses, e-commerce fulfillment centers, and production lines to track worker productivity and time efficiency in real time.

## Key Features

- **Worker time tracking** — log in/out per task or shipment
- **ShipStation integration** — syncs order and shipment data automatically
- **Productivity reports** — per worker, per shift, per department
- **Performance dashboards** — visual KPIs for managers
