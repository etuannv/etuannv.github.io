## Overview

A two-module system that scrapes license data (automotive, contractor) from government sources daily, tracks new licenses, and monitors status changes of existing ones.

## Modules

1. **Scraper** — daily automated collection from public license databases
2. **Dashboard** — searchable web interface with license status, history, and alerts
